在 `mobile/` 目录运行以下命令，并将 `KKDESK_SHOT_PLATFORM` 设为 `ios` 或 `android`。Android 需要设置 `ANDROID_HOME`，并先确认系统的首次全屏提示。

```sh
flutter drive -d "$KKDESK_SHOT_DEVICE" --debug \
  --target integration_test/demo_screens.dart \
  --driver test_driver/ui_round_two_test.dart
```
