# 设置

**设置** 页左边是分组：安全、画质、网络、通用。改动立即生效并保存到本机的配置文件。

<img class="shot" src="/screenshots/page-settings.png" alt="设置 › 安全">

## 安全

| 设置 | 说明 |
|---|---|
| 临时密码更换 | 每次连接后更换（默认）、每 12 小时、每 24 小时、不自动更换。和连接页上的同名下拉框是同一个设置。 |
| 固定密码 | 8–16 位。设置后，临时密码和固定密码都能用来连接本机；可以清除。修改后旧的固定密码立即失效。 |
| 连接前需要确认 | 默认开启：有人连接时弹窗，由你决定是否接受。关闭后，密码正确的局域网连接会被自动接受（跨网设备码连接仍要确认）。 |
| 允许被远程控制 | 启动 kkdesk 时是否自动开启被控。连接页上的开关只改变本次运行。 |

## 画质

| 设置 | 说明 |
|---|---|
| 默认帧率 | 30、60、90、144 fps。新会话使用，会话中可以在控制中心临时修改。 |
| 默认码率 | 自动、30、14、8、3 Mbps。「自动」目前固定为 8 Mbps。 |

## 网络

| 设置 | 说明 |
|---|---|
| 监听端口 | 默认 21118，范围 1024–65535。点 **应用** 后立即在新端口监听，进行中的会话不受影响。端口被系统保留时 kkdesk 会自动换一个并保存，见 [安装与首次运行](./install#端口被系统保留)。 |
| 本机地址 | 只读，把地址和端口告诉对方即可连接。 |
| 跨网服务、服务密钥 | 跨网服务的 HTTPS 地址和 `KKDESK_SERVER_TOKEN`，见 [跨网连接](./remote)。 |

## 通用

| 设置 | 说明 |
|---|---|
| 主题 | 跟随系统、浅色、深色，立即切换。 |
| 版本 | 当前版本号。用 `tan dev` 运行时显示 `kkdesk dev`。 |
| 配置文件 | 配置文件的位置，点按钮在访达（Windows 上是资源管理器）中显示。 |

## 配置文件

设置和「我的设备」都保存在 `kkdesk.json`：

| 系统 | 位置 |
|---|---|
| macOS | `~/Library/Application Support/kkdesk/kkdesk.json` |
| Windows | `%APPDATA%\kkdesk\kkdesk.json` |

- 环境变量 `KKDESK_CONFIG_DIR` 可以指定另一个目录，例如在 `tan dev` 旁边再开一个测试实例。
- 文件写入是原子的（先写临时文件再改名）。文件损坏时会备份为 `kkdesk.json.bad`，并用默认设置启动，界面上会提示原因。
- [命令行参数](/dev/cli) 优先于配置文件。
