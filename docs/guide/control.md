# 远程控制与控制中心

连接成功后，控制端会打开会话窗口：上方是标签栏，下方是对方的屏幕。

## 标签栏

- 标签上显示对方地址和实时延迟：绿色低于 30 ms，金色低于 80 ms，红色更高。
- 点标签上的 × 关闭会话。
- 右侧的状态标签：「仅查看」表示当前不发送操作。

## 操作对方电脑

在「远程控制」方式下，窗口里的鼠标移动、点击、滚轮和键盘输入都会发给对方。

- 被控端是 macOS 时需要「辅助功能」权限，否则操作不会生效，见 [安装与首次运行](./install#辅助功能权限-被别人控制时)。
- 连接本机自己（地址是本机或 127.0.0.1）时会强制「仅查看」，避免鼠标操作自己造成连锁反应。

## 控制中心

点标签栏右边的 **控制中心** 按钮，弹出菜单：

| 菜单项 | 作用 |
|---|---|
| 画质 | 码率：自动、30、14、8、3 Mbps。「自动」目前固定为 8 Mbps。 |
| 帧率 | 30、60、90、144 fps。 |
| 窗口 › 自适应 | 默认等比缩放，将完整远程画面放入窗口。 |
| 窗口 › 实际大小 1:1 | 一个视频像素对应一个本机屏幕像素。画面超出窗口时，可用底部滑块平移。 |
| 窗口 › 进入／退出全屏 | 切换系统全屏，退出时恢复窗口大小。 |
| 真彩、HDR | 暂未支持，显示为灰色。 |
| 中继连接 | 只读。勾上表示当前经跨网服务的 TURN 中继传输。 |
| 仅查看 | 勾上后不再发送键盘鼠标操作，也不同步剪贴板；再点一次恢复控制。 |
| 隐私屏 | 遮住被控端的所有显示器。远程画面继续显示，共享和操作权限保持当前设置。 |
| 本次断开后锁屏 | 为当前会话开启断开后锁屏。被控端面板会显示「本次会话结束后将锁屏」。 |
| 锁屏并断开 | 锁定被控端。等系统确认锁定后结束会话，锁屏失败时显示原因并保留连接。 |
| 解锁电脑… | 对方锁屏时可见。控制会话可输入对方登录密码或 PIN，也可使用此前保存的凭据。 |
| 工具 › 文件传输 | 打开这个会话的文件传输窗口。 |
| 退出远控 | 结束会话。 |

画质和帧率只改当前会话。新会话的默认值在 [设置 › 画质](./settings#画质) 里改。

## 隐私屏与锁屏

电脑控制端的远程控制和仅查看会话都可以使用这三项操作。仅传文件会话没有这些入口。

开启隐私屏取决于被控端的安全设置。需要同意时，控制端显示「等待对方同意…」，被控端有 30 秒可以选择允许或拒绝。被控端回报生效后，控制中心才会显示勾选。

在被控端按 **⌃⌥⌘P**（macOS）或 **Ctrl+Alt+Shift+P**（Windows）可以退出隐私屏。被控端通过快捷键退出后，同一次会话里再次开启需要当地用户同意。被控端把隐私屏策略改为「不允许」时，当前遮罩会撤掉。

开启断开后锁屏时，主动断开或正常退出 kkdesk 会立即锁屏。意外断开后保留现有遮罩并显示 60 秒倒计时。在倒计时期间接受新连接会取消这次锁屏。被控端也可以用隐私屏的退出快捷键取消，或在界面可见时点击「取消锁屏」。

Windows 隐私屏需要 Windows 10 2004（build 19041）或更新版本。Windows 的开始菜单、Alt+Tab 切换界面、通知中心、系统通知和 UAC 安全桌面可能出现在遮罩上方。

macOS 锁屏使用系统私有接口，系统更新可能影响可用性。macOS 的 ⌘Tab 切换器、系统通知和 Spotlight 的遮盖效果待真机验证。

Windows 被控端安装锁屏远控组件后，可以从远控会话看见和操作锁屏界面。也可点「解锁电脑…」，按锁屏界面要求输入登录密码或 PIN。勾选「记住密码」可在成功解锁后把密码保存到控制端的系统凭据库。「忘记解锁密码」可删除保存值。组件不可用时，控制中心会显示原因。

macOS 被控端也可在正式签名的 kkdesk 中安装锁屏远控组件。目前 GitHub Releases 发布的 macOS 版没有用开发者证书签名，**不支持锁屏远控**，设置页会显示「需要正式签名的 kkdesk」；需要时请用自己的 Apple 开发者证书[从源码构建并签名](/dev/build)。首次使用请先确认系统批准、屏幕录制和辅助功能权限，按[实测说明](./macos-lockscreen-test)验证锁屏画面和输入。

kkdesk 崩溃或被强制结束时，遮罩会随进程消失，无法保证锁屏。

## 被控端看到什么

被控端右下角有一个「正在控制本机」面板，显示对方地址和已连接时长，以及本次会话的权限：

- **键盘鼠标**：一直开启。
- **剪贴板**、**文件传输**：点一下就能关掉或打开，立即生效。
- **声音**：暂未支持。

点 **断开** 立即结束会话。
