# 远程控制与控制中心

连接成功后，控制端会打开会话窗口：上方是标签栏，下方是对方的屏幕。

## 标签栏

- 标签上显示对方地址和实时延迟：绿色低于 30 ms，金色低于 80 ms，红色更高。
- 点标签上的 × 关闭会话。
- 右侧的状态标签：「仅查看」表示当前不发送操作。

## 操作对方电脑

在「远程控制」方式下，窗口里的鼠标移动、点击、滚轮和键盘输入都会发给对方。

- 被控端是 macOS 时需要「辅助功能」权限，否则操作不会生效，见 [安装与首次运行](./install#辅助功能权限-被别人控制时)。
- 连接本机自己（地址是本机或 127.0.0.1）时会强制「仅查看」，避免鼠标操作自己造成连锁反应。

## 控制中心

点标签栏右边的 **控制中心** 按钮，弹出菜单：

| 菜单项 | 作用 |
|---|---|
| 画质 | 码率：自动、30、14、8、3 Mbps。「自动」目前固定为 8 Mbps。 |
| 帧率 | 30、60、90、144 fps。 |
| 真彩、HDR | 暂未支持，显示为灰色。 |
| 中继连接 | 只读。勾上表示当前经跨网服务的 TURN 中继传输。 |
| 仅查看 | 勾上后不再发送键盘鼠标操作，也不同步剪贴板；再点一次恢复控制。 |
| 工具 › 文件传输 | 打开这个会话的文件传输窗口。 |
| 退出远控 | 结束会话。 |

画质和帧率只改当前会话。新会话的默认值在 [设置 › 画质](./settings#画质) 里改。

## 被控端看到什么

被控端右下角有一个「正在控制本机」面板，显示对方地址和已连接时长，以及本次会话的权限：

- **键盘鼠标**：一直开启。
- **剪贴板**、**文件传输**：点一下就能关掉或打开，立即生效。
- **声音**：暂未支持。

点 **断开** 立即结束会话。
