# Windows 锁屏远程操作实测

准备 Windows 10 1809 或 Windows 11 x64 本地控制台、同版本的 Mac 控制端，以及能在 Windows 本机手动解锁的测试账户。安装和卸载需要 Windows 管理员批准。试错前请确认测试账户能按本机策略恢复。

## 1. 校验并安装

在 Windows PowerShell 中进入包目录，运行 `Get-FileHash .\kkdesk.exe -Algorithm SHA256`。结果应与随包的 `SHA256SUMS` 一致。

用普通用户权限打开下载目录里的 `kkdesk.exe` 。在「设置 › 安全 › 锁屏时允许远程操作」点「安装」，并在系统提示中批准。安装成功后，窗口应关闭并自动重新打开。设置页应显示「已安装」。

在任务管理器的「详细信息」页显示「映像路径名称」和「已提升」列。核对桌面窗口对应的 `kkdesk.exe` 路径为 `%ProgramFiles%\kkdesk\kkdesk.exe`，且「已提升」为「否」。服务和锁屏助手也可能出现在进程列表中。

退出桌面窗口，再从下载目录双击同一个 `kkdesk.exe`。确认只出现一个桌面窗口，任务管理器显示它从安装位置运行。连接时使用安装副本显示的临时密码或已配置的固定密码。

如需验证手动切换，先退出桌面窗口，再在下载目录的 PowerShell 运行 `.\kkdesk.exe -applog "$env:TEMP\kkdesk-portable.log"`。该参数会跳过自动切换。安全设置应显示「已安装，当前 kkdesk 未从安装位置运行」。点击「从安装位置重新启动」后，再核对路径和权限。

## 2. 锁屏画面与手动解锁

从 Mac 建立普通远控会话，在 Windows 本机按 **Win+L**。确认 Mac 能看到锁屏画面且会话不断。通过远控键盘唤醒登录界面，输入测试账户要求的密码或 PIN。确认解锁后能继续看到和操作桌面。

可用下面几种情况核对控制端横幅。每次先在 Windows 本机退出锁屏，准备好对应状态，再连接并锁屏。

| Windows 被控端状态 | 控制端预期 |
| --- | --- |
| 组件未安装 | 对方电脑未安装锁屏远控组件 |
| 组件已安装，从下载目录运行同一份程序，并通过上述 `-applog` 参数跳过自动切换 | 对方的 kkdesk 未从安装位置运行 |
| 安装版运行中，在管理员 PowerShell 用 `Stop-Service KKDeskLockScreen` 停止服务 | 对方锁屏远控服务未运行或无法连接助手 |
| 新版下载包运行中，组件仍是旧版 | 请在对方电脑上更新锁屏远控组件 |

服务停止测试后，在本机解锁并运行 `Start-Service KKDeskLockScreen`，或在安全设置点「启动服务」。若出现「对方锁屏远控组件出错，详见对方日志」，记录本机日志里 `start lock screen capture` 后面的具体错误。

如果 Windows 要求 **Ctrl+Alt+Del**，从 Mac 的远程键盘发送对应组合键。系统「禁用或启用软件安全注意序列」策略需要允许服务模拟该序列。应用不会更改策略。请记录当前策略和画面表现。

## 3. 控制中心解锁与保存密码

1. 再锁屏一次，从 Mac 打开「控制中心 › 解锁电脑…」。确认「记住密码」默认未勾，并输入 Windows 登录界面当前要求的密码或 PIN。确认远程画面返回桌面。
2. 再锁屏，输入正确凭据并勾选保存。成功后重新锁屏，再点击「解锁电脑…」，应直接提交。连接本身不会触发解锁。
3. 用可恢复的测试账户验证错误密码。更改 Windows 登录凭据后锁屏，使用保存的旧值，等待「已保存的解锁密码不正确」。在控制中心选「重新输入」，填新值并勾选保存，确认下一次仍可一键解锁。点「忘记解锁密码」后，再试一次应打开输入框。
4. 锁屏时勾选「仅查看」，确认解锁菜单隐藏。取消后确认恢复。仅传文件会话也没有解锁入口。
5. 在测试账户的策略允许时，检查同一会话最多接受三次解锁请求。第 4 次应提示「本次连接的解锁尝试次数已达上限」。

## 4. 复连、升级与卸载

1. 核对复连的批准策略。要求本机确认时，锁屏复连仍须完成确认。可在受控测试环境使用既有自动接受设置和正确连接密码验证远控复连。
2. 若有另一版本，退出安装副本并启动新包。新版应继续从下载目录运行，安全设置应提示「锁屏远控组件需要更新」。批准更新后，窗口应自动从安装位置重新打开。核对进程路径后复测锁屏。
3. 在安全设置点「卸载」并批准。也可从原始测试包在管理员 PowerShell 执行 `.\kkdesk.exe -uninstall-service`。用 `sc.exe query KKDeskLockScreen` 确认服务已移除。Windows 可能在重启后才清理卸载时正在使用的文件。
4. 启动普通测试包，远程连接后再按 Win+L。控制端应提示「对方电脑未安装锁屏远控组件」，并禁用「解锁电脑…」。本机手动解锁后核对画面是否恢复。

回传 Windows 版本、各步骤表现与失败原因。应用日志默认位于 `%APPDATA%\kkdesk\kkdesk.log`。需要服务诊断时，可在卸载前查看 `%ProgramFiles%\kkdesk\lockscreen-service.log`。发送日志前可遮盖用户名相关路径和 SID，请勿回传登录密码、PIN 或显示凭据的截图。
