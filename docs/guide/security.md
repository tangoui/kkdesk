# 安全与权限

## 谁能连进来

| 连接方式 | 需要什么 | 被控端确认 |
|---|---|---|
| 局域网 | 正确的临时密码或固定密码 | 默认需要；关掉「连接前需要确认」后自动接受 |
| 跨网（设备码） | 设备码，以及两边配置同一个跨网服务和服务密钥 | **每次都需要** |

- 关掉「允许被远程控制」后，kkdesk 不再监听，也不在跨网服务上线，谁都连不进来。
- 同一时间只接受一个控制端。

## 密码怎么用

- 局域网连接用挑战应答验证密码：被控端发一个随机数，控制端用密码对它做 HMAC-SHA256 后返回。**密码本身不在网络上传输**，每次连接的随机数都不同，抓包重放没有用。
- 临时密码是 6 位，数字和大小写字母混合（不含容易看错的 0、O、o、1、l、I），区分大小写，默认 **每次连接后更换**：上一次给出去的密码，会话结束后就不能再用了。
- 固定密码 8–16 位，适合连接自己的电脑。修改或清除后，旧的固定密码立即失效。
- 连接请求弹窗有 30 秒期限，超时自动拒绝。

::: tip 不认识的人请拒绝
接受连接后，对方能看到你的屏幕；如果给了键盘鼠标权限，对方就能操作你的电脑。
:::

## 会话中的权限

被控端可以在连接请求弹窗里先取消勾选，也可以在会话中通过右下角的「正在控制本机」面板、或「远程会话」页随时开关：

| 权限 | 默认 | 说明 |
|---|---|---|
| 键盘鼠标 | 开 | 远程控制方式下一直开启。不想被操作，请让对方用「仅查看」连接。 |
| 剪贴板 | 开 | 关掉后两个方向都不再同步。 |
| 文件传输 | 开 | 关掉后对方不能浏览本机文件，进行中的传输立即中止。 |
| 声音 | — | 暂未支持。 |

## 传输加密

画面、操作、剪贴板和文件都走 WebRTC：媒体用 SRTP 加密，数据通道用 DTLS 加密。走跨网服务的 TURN 中继时，服务器转发的也是加密后的数据。

## 数据保存在哪里

kkdesk 没有账号系统。设置、我的设备、当前临时密码都保存在本机的 `kkdesk.json`，不会上传（位置见 [设置](./settings#配置文件)）。跨网服务只知道设备码和在线状态，配对状态只保存在服务端内存里。

## 系统权限

| 系统 | 权限 | 用途 |
|---|---|---|
| macOS | 屏幕录制（录屏与系统录音） | 被控端共享屏幕 |
| macOS | 辅助功能 | 被控端执行对方的键盘鼠标操作 |
| Windows | 防火墙放行 | 别的电脑连进来 |
| Windows | 管理员 | 以普通权限运行时，无法操作管理员窗口和 UAC 弹窗 |
