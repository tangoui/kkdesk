# 安全与权限

## 连接认证

使用局域网地址或跨网设备码连接时，请先把控制端和被控端都升级到最新版 kkdesk。跨网设备码连接也必须填写临时密码或固定密码。

| 连接方式 | 控制端如何核对电脑身份 |
|---|---|
| 局域网 | 第一次成功连接时会记住该地址的身份，并显示对方设备码。可以和被控端「连接」页显示的本机设备码核对。之后身份不符时会拒绝连接。 |
| 跨网（设备码） | 控制端先验证应答的签名，再核对签名公钥是否对应输入的设备码。 |

控制端验证被控端签名后，才通过 WebRTC 的 DTLS 加密数据通道发送这次连接专用的密码证明。密码和证明都不会出现在交换连接信息的信令里。局域网首次连接时，核对设备码能帮助发现冒充的电脑。

被控端连续收到 5 次错误密码后暂停密码连接 30 秒。暂停结束后继续输错，暂停时间每次翻倍，最长 15 分钟。暂停中的尝试不计数，成功验证一次密码或重启被控端会清零。已配对手机的签名连接可照常使用。

## 密码与确认

- 临时密码是 6 位，包含数字和大小写字母，区分大小写。刷新后旧密码立即失效。
- 固定密码适合连接自己的电脑。修改或清除后，旧的固定密码立即失效。
- 「连接前需要确认」启用时，通过密码验证后仍需在被控端接受。确认窗口 30 秒后自动拒绝。
- 被控端同一时间只接受一个控制端。关闭「允许被远程控制」会停止监听和跨网注册。
- 手机没收到最后一条配对确认时，可在电脑上重新打开配对页面，再扫码或输入新的手动配对码补存记录。

::: tip 不认识的人请拒绝
接受连接后，对方能看到你的屏幕；如果给了键盘鼠标权限，对方就能操作你的电脑。
:::

## 会话中的权限

被控端可以在连接请求弹窗里先取消勾选，也可以在会话中通过右下角的「正在控制本机」面板、或「远程会话」页随时开关：

| 权限 | 默认 | 说明 |
|---|---|---|
| 键盘鼠标 | 开 | 远程控制方式下一直开启。不想被操作，请让对方用「仅查看」连接。 |
| 剪贴板 | 开 | 关掉后两个方向都不再同步。 |
| 文件传输 | 开 | 关掉后对方不能浏览本机文件，进行中的传输立即中止。 |
| 声音 | — | 暂未支持。 |

## 传输加密

画面、操作、剪贴板和文件都走 WebRTC：媒体用 SRTP 加密，数据通道用 DTLS 加密。走跨网服务的 TURN 中继时，服务器转发的也是加密后的数据。

## 数据保存在哪里

kkdesk 没有账号系统。设置、我的设备、当前临时密码都保存在本机的 `kkdesk.json`，不会上传（位置见 [设置](./settings#配置文件)）。被控端的身份密钥和已配对的手机记录保存在本机。局域网身份记录在桌面端保存在「我的设备」，在手机端保存在应用的本地设置。跨网服务在内存中保留在线设备和信令转发状态。

## 系统权限

| 系统 | 权限 | 用途 |
|---|---|---|
| macOS | 屏幕录制（录屏与系统录音） | 被控端共享屏幕 |
| macOS | 辅助功能 | 被控端执行对方的键盘鼠标操作 |
| Windows | 防火墙放行 | 别的电脑连进来 |
| Windows | 管理员 | 以普通权限运行时，无法操作管理员窗口和 UAC 弹窗 |
