# 简介

kkdesk 是一个用 [Tango](https://github.com/tangoui/tango) 写的远程桌面。它是一个 Go 程序，界面自绘，远端画面用系统原生的视频视图显示。

一个 kkdesk 同时有两种角色：

- **被控端**：共享本机屏幕，接受别人的键盘鼠标操作。
- **控制端**：查看或控制别的电脑。

两台电脑都装同一个 kkdesk，谁控制谁只取决于谁去连谁（Windows 目前只能被控，见下面的[平台现状](#平台现状)）。

## 能做什么

| 功能 | 说明 |
|---|---|
| 局域网连接 | 输入对方的「地址:端口」和 6 位临时密码，对方确认后连接。见 [局域网连接](./connect-lan)。 |
| 跨网连接 | 自己部署 `kkdesk-server`，用 `KD-` 开头的设备码连接异地电脑。见 [跨网连接](./remote)。 |
| 三种连接方式 | 远程控制、仅查看、传文件（只开文件窗口，不共享屏幕）。 |
| 控制中心 | 会话中切换画质和帧率、切换仅查看、打开文件传输、退出远控。见 [远程控制与控制中心](./control)。 |
| 文件传输 | 浏览对方的文件，上传下载文件和文件夹，校验完整性。见 [文件传输](./file-transfer)。 |
| 剪贴板同步 | 两边复制的文字自动同步。见 [剪贴板](./clipboard)。 |
| 我的设备 | 连接过的电脑自动记下，可分组、改名，后台探测是否在线。见 [我的设备与远程会话](./devices)。 |

## 平台现状

kkdesk 还在验证原型阶段。

| 平台 | 被控端 | 控制端 | 说明 |
|---|---|---|---|
| macOS | ✅ | ✅ | ScreenCaptureKit 采集，VideoToolbox H.264 硬件编解码，CGEvent 注入。 |
| Windows（x64） | 实机验证中 | 只能「传文件」 | 被控端：DXGI Desktop Duplication 采集，Media Foundation H.264 编码（优先硬件），SendInput 注入。控制端的解码和画面显示还没实现，暂时不能远程控制或查看别的电脑。 |

暂不支持：Windows 作控制端看画面、声音、剪贴板里的图片和文件、真彩（4:4:4）和 HDR、多显示器切换。

## 连接是怎么走的

```
局域网：  控制端 ──── 信令（TCP，口令挑战）────▶ 被控端
               ◀──── WebRTC 视频 + 数据通道 ────▶      不经过任何服务器

跨网：    控制端 ──▶ kkdesk-server（设备码信令） ◀── 被控端
               ◀──── WebRTC 直连，打不通时走 TURN 中继 ────▶
```

视频是 H.264，走 WebRTC 的 RTP；键盘鼠标、画质切换、时钟同步、剪贴板和文件传输都走 WebRTC 数据通道。细节见 [架构](/dev/architecture)。
