# 局域网连接

两台电脑在同一个局域网（连同一个路由器或 Wi-Fi，地址在同一网段）时，用地址和临时密码就能直接连接。画面和操作只在两台电脑之间传，不经过任何服务器。

## 被控端：把地址和密码告诉对方

打开 kkdesk，在 **连接** 页左边的「允许控制本机」卡片里：

1. 打开 **允许被远程控制**。侧边栏底部显示「服务正常 · 端口 21118」表示正在等待连接。
2. 把 **本机地址** 和 **临时密码** 告诉对方。点 **复制并分享** 会复制成一段话，可以直接发到微信：

   ```
   用 kkdesk 远程协助我：
   地址 192.168.1.28:21118
   临时密码 k7Pm4x
   ```

本机地址可能有好几个。排在第一个的是实际上网用的网卡，通常就是对方要填的地址；Hyper-V、WSL、Docker、虚拟机的虚拟网卡排在最后，别的电脑访问不到它们。

### 临时密码

- 每个临时密码 6 位，数字和大小写字母混合，区分大小写；不含容易看错的 0、O、o、1、l、I。点刷新按钮可以立刻换一个，旧密码马上失效。
- 更换频率可选：**每次连接后更换**（默认）、每 12 小时、每 24 小时、不自动更换。
- 想用一个长期不变的密码，可以在 [设置 › 安全](./settings#安全) 里设 **固定密码**（8–16 位）。设了之后，临时密码和固定密码都能用来连接。

## 控制端：输入地址和密码

在 **连接** 页右边的「控制其他电脑」卡片里：

1. **对方地址或设备码** 填 `192.168.1.28:21118`。省略端口时默认用 21118。两台电脑不在同一个网络时改填对方的跨网设备码，见 [跨网连接](./remote)。
2. **临时密码** 填对方给的 6 位临时密码（注意大小写），或对方的固定密码。
3. 选 **连接方式**：

   | 方式 | 效果 |
   |---|---|
   | 远程控制 | 看到对方屏幕，键盘鼠标操作会发给对方。 |
   | 仅查看 | 只看画面，不发送任何操作。 |
   | 传文件 | 只打开文件传输窗口，对方不共享屏幕。 |

4. 点 **连接**。

### 核对设备身份

两端都要升级到最新版。第一次成功连接时，控制端显示「对方设备码」，可和被控端「连接」页的本机设备码核对。同一地址之后只接受记住的电脑身份。

如果提示身份变了，先向对方确认是否重装了 kkdesk。确认后，电脑端可在「我的设备」删除对应条目，手机端可点「忘记这台电脑的身份」并确认。重新连接时会记录新的身份。

## 被控端确认

默认每次有人连接，被控端都会弹出「连接请求」，显示对方地址和本次要给的权限（键盘鼠标、剪贴板、文件传输）。可以在弹窗里先取消勾选某些权限，再点 **接受**。

- 30 秒内不处理会自动拒绝。
- 在 [设置 › 安全](./settings#安全) 关掉「连接前需要确认」后，密码正确的连接会被自动接受。

连接成功后，控制端会打开会话窗口，被控端右下角出现「正在控制本机」面板，可以随时开关权限或 **断开**。

## 连不上时

| 提示 | 原因与处理 |
|---|---|
| 因多次密码错误暂停了连接 | 等提示中的秒数结束，再用正确密码连接。 |
| 身份签名无效 | 确认两端都已升级到最新版，再核对地址。 |
| 密码错误 | 临时密码可能已经更换（默认每次连接后更换），请对方重新报一次。 |
| 对方没有开启远程控制 | 对方没打开「允许被远程控制」，或端口填错了。 |
| 网络不通，两台电脑可能不在同一个局域网 | 两台电脑不在同一网段，例如接在不同的路由器下，或者一台在访客网络里。把两台接到同一个路由器，或者改用 [跨网连接](./remote)。 |
| 连接超时 | 对方防火墙拦截了，或两台电脑根本不在同一张网络里。见 [常见问题](./faq)。 |
