# 文件传输

kkdesk 可以在两台电脑之间传文件和文件夹，走的是会话的 WebRTC 数据通道，和画面同一条连接。

## 打开文件窗口

三种方式：

- 远程控制中：**控制中心 › 工具 › 文件传输**。
- 只想传文件：连接时选 **传文件** 方式，对方不共享屏幕，只打开文件窗口。
- **文件传输** 页：在「已连接的会话」卡片上点 **打开文件传输**，或者在「仅传文件」里输入地址和密码，点 **连接并传文件**。

## 文件窗口

窗口分左右两栏：左边是**本机**，右边是**对方**。

- 在路径框里输入路径后按回车跳转，**上级** 回到上一层，**刷新** 重新读取。
- 选中文件或文件夹后，点 **上传 →** 传到对方当前目录，点 **← 下载** 传回本机当前目录。
- **新建文件夹** 在当前目录里新建。
- 一个目录最多列出前 5000 项，超出时列表底部会提示「只显示前 … 项」。

窗口下方是 **传输队列**，显示每个传输的进度、剩余时间、文件数和平均速度。进行中的传输可以单独 **取消**，**清除已完成** 清掉已结束的条目。符号链接和特殊文件会被跳过，并在队列里注明。

## 可靠性

- 每个文件传完后校验大小和 SHA-256，不一致时删除不完整的文件并提示「校验失败」。
- 传输中的文件先写成隐藏的临时文件 `.<文件名>.kkdesk-part`，完成并校验通过后才改成正式名字。
- 目标位置已有同名文件或文件夹时不会覆盖，而是自动改名为 `名称 (1).扩展名`、`名称 (2).扩展名`……
- 关闭窗口时如果还有传输没完成，会先询问；确认关闭会取消这些传输，传了一半的文件会被删除。

## 权限

被控端的「文件传输」权限默认开启。被控端可以在连接请求弹窗里取消勾选，或在「正在控制本机」面板、「远程会话」页里随时关掉；关掉后正在进行的传输立即中止，控制端看到「对方已关闭文件访问」。

## 传输记录

**文件传输** 页下方列出本次运行的传输记录：时间、文件名、方向、大小、平均速度和结果。记录只保存在内存里，退出 kkdesk 后清空，也可以点 **清空**。

## 常见错误

| 提示 | 含义 |
|---|---|
| 对方已关闭文件访问 | 被控端关掉了「文件传输」权限。 |
| 没有权限 | 系统不允许 kkdesk 读写这个位置。 |
| 磁盘已满 | 目标磁盘空间不够。 |
| 对方的 kkdesk 版本不兼容，请升级 | 两边的文件传输协议版本不同。 |
| 对方没有响应 | 网络中断或对方卡住了。 |
