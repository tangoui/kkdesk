# 跨网连接（设备码）

两台电脑不在同一个局域网（例如一台在公司、一台在家）时，局域网直连走不通。kkdesk 的跨网连接需要你**自己部署一台跨网服务** `kkdesk-server`，它负责：

- **信令**：两边通过它找到对方，用设备码代替 IP 地址；
- **TURN 中继**：两边无法直接打通时，画面和操作经它中转。

能直连时，画面和操作仍然只在两台电脑之间传。服务端的部署见 [部署跨网服务](/deploy/server)。

## 1. 两台电脑都填上跨网服务

在 **设置 › 跨网连接** 里填写：

- **跨网服务**可填域名 HTTPS 地址，例如 `https://desk.example.com`，或公网 IP 地址，例如 `https://203.0.113.10:8443`。
- **服务器公钥**在公网 IP 公钥模式下填写，复制服务端提供的值。使用域名 HTTPS 证书时留空。
- **服务密钥**：服务器上 `KKDESK_SERVER_TOKEN` 的值。

点 **保存跨网配置**。两台电脑要填同一个地址、服务密钥，以及 IP 模式下的服务器公钥。TURN 密钥只留在服务器上。[读取服务器公钥和服务密钥](/deploy/server#_3-读取客户端配置)

## 2. 被控端复制设备码

被控端打开「允许被远程控制」，连接页会显示 **本机跨网设备码**，以 `KD-` 开头。点复制按钮发给对方。

::: tip 设备码固定不变
设备码由本机的设备身份生成，重启 kkdesk 后不变，复制一次即可长期使用。删除 kkdesk 的数据目录后，重新生成的设备身份会有新的设备码。如果本机设备身份无法读取，被控端会显示错误并停止接受连接。
:::

## 3. 控制端用设备码连接

两台电脑都需要升级到最新版。在「控制其他电脑」的 **对方地址或设备码** 里粘贴设备码（输入框下方会显示「跨网连接」），**临时密码** 填对方的临时密码或固定密码，点 **连接**。

- 对方开着「连接前需要确认」时，对方点接受后连上；关掉时直接连上，适合远程自己的电脑。
- 控制端先验证对方签名和设备码，再通过 WebRTC 加密通道发送本次连接的密码证明。
- 如果提示对方身份与设备码不符，请让对方核对并重新发送连接页显示的设备码。签名无效时，请确认两端都已升级。
- 如果提示因多次密码错误暂停连接，请按提示等候，再用正确密码连接。

## 直连还是中继

kkdesk 会自动选：能直连就直连，打不通时走服务器上的 TURN 中继。会话中打开 **控制中心**，「中继连接」被勾上表示当前走的是中继。中继时延迟和带宽取决于服务器的线路。

## 当前限制

- 服务端是单实例，所有设备共用一个服务密钥。
- 设备上线和配对状态只保存在服务端内存里。服务端重启或网络中断后，被控端每 3 秒自动重连一次，设备码不变。
