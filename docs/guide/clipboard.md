# 剪贴板

远程控制时，两台电脑复制的**文字**会自动同步：在一边复制，到另一边直接粘贴。

## 怎么同步

- 两边各自每 0.5 秒看一次本机剪贴板，**内容变了才发给对方**。
- 连接之前剪贴板里已有的内容不会发出去，只有连接之后新复制的才同步。
- 收到的内容写进本机剪贴板，不会再发回去，两边不会来回回弹。
- 单次最多 1 MiB 文字，更长的不发送。

## 什么时候不同步

| 情况 | 说明 |
|---|---|
| 被控端关掉了「剪贴板」权限 | 两个方向都停。可以在连接请求弹窗里取消勾选，或在「正在控制本机」面板、「远程会话」页里随时开关。 |
| 控制端是「仅查看」 | 既不发送，也不接收。切回「远程控制」后恢复。 |
| 「传文件」方式的连接 | 只传文件，不同步剪贴板。 |
| 被控端还没接受连接 | 被控端确认之前收到的内容一律丢弃。 |

## 暂不支持

- **图片和文件**：剪贴板里是图片或文件时不会同步，也不会清空对方的剪贴板。传文件请用 [文件传输](./file-transfer)。
- 富文本格式：只同步纯文字。
