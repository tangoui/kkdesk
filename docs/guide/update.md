# 自动更新

kkdesk 能自己更新：发现新版本时弹出「软件更新」窗口，下载、安装并重启到新版本。

## 什么时候检查

- **自动**：启动 30 秒后检查一次，之后每 24 小时检查一次（跨启动计算，不会每次打开都查）。没有新版本或检查失败时不打扰你，只有发现新版本才弹窗。
- **手动**：**设置 › 通用**，在版本号旁边点 **检查更新**。

## 更新窗口

发现新版本时，窗口显示版本号、发布日期和更新说明：

| 按钮 | 作用 |
|---|---|
| 下载并安装 | 下载新版本。能用增量补丁时只下载改动的部分（通常只有完整包的百分之几），失败会自动改下完整包。 |
| 稍后提醒 | 本次运行内不再提醒。 |
| 跳过此版本 | 以后不再提醒这个版本；更新的版本照常提醒。 |

下载完成后可以选 **立即重启**，或 **下次启动时安装**。安装时 kkdesk 会先退出，替换后自动打开新版本。

::: warning 正在远程控制时
更新会重启 kkdesk，进行中的会话会断开。正在被别人控制或正在控制别人时，建议先选「下次启动时安装」。
:::

## 安全

- 每个版本的更新清单都用 kkdesk 的发布密钥签名（Ed25519），程序里内置了对应的公钥。签名不对、版本比当前旧、清单过期的更新一律拒绝。
- 下载的文件逐个校验大小和 SHA-256，安装前再校验一次。
- macOS 上，新版本的代码签名必须和当前版本是同一个开发者，否则不安装。
- 新版本启动后会向更新程序报告「启动成功」。如果新版本 60 秒内没能启动（崩溃、卡死），会**自动回滚**到原来的版本，并在下次打开时告诉你。

## 支持的安装方式

| 系统 | 能自动更新的安装方式 |
|---|---|
| macOS | 从 `kkdesk.app` 运行（建议放进「应用程序」文件夹）。在挂载的磁盘映像里直接运行时不能更新，请先拖到「应用程序」。 |
| Windows | 直接运行 `kkdesk.exe`。exe 所在的文件夹需要可写。 |
| Linux | 解压到 kkdesk 自己的文件夹里运行（例如 `~/apps/kkdesk-0.1.0-linux-amd64/`）。 |

以下情况不会自动更新：用 `tan dev`、`go run` 或 `go build` 构建的开发版（只有 `tan build` 打出的发布包会更新）、用 `-host`、`-connect` 启动的测量模式，以及设置了环境变量 `KKDESK_NO_UPDATE` 时。

::: tip macOS 权限会保留
发布版用固定的开发者证书签名，自动更新后「屏幕录制」「辅助功能」权限不用重新授权。
:::
