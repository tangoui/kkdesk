# kkdesk 导航页面：我的设备、远程会话、文件传输、设置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 主窗口左侧导航除「连接」外的四个页面目前只有「即将推出」占位（用户 2026-11-25 指出），把它们做成可用的页面；没有账号系统，数据存在本机。

**Architecture:** 新增 `internal/config`：本机配置与通讯录，JSON 文件放在用户配置目录（macOS `~/Library/Application Support/kkdesk/`，Windows `%APPDATA%\kkdesk\`，`os.UserConfigDir()`），原子写（临时文件 + 重命名），读写有锁，损坏时备份为 `.bad` 并用默认值。页面在 `internal/ui`，每页一个文件；会话与传输的运行时数据由 `internal/app` 提供只读快照（`Sessions()`、`TransferHistory()`）。

**Tech Stack:** Go、Tango ui（Ant Design 6.7 外观）。

**设计来源:** `docs/design/prototype.html`（我的设备页的表格与分组、设备详情的操作按钮；设置页的分栏表单）。

## Global Constraints

- **我的设备**：
  - 通讯录条目 `{id, name, addr, group, os?, lastConnected, note}`。
  - 连接成功时自动添加或更新（按地址去重，名称默认取地址）。
  - 可以手动添加、改名、移动分组、删除，删除前要确认。
  - 分组默认「我的电脑」，可以新建分组。
  - 列表按分组显示，包含：名称、地址、状态、最近连接。状态由后台每 10 秒探测一次对方 TCP 端口，显示「在线」「离线」「探测中」，探测超时 800 ms，并发有上限。
  - 每行有「连接」「仅查看」「传文件」三个按钮，点击时弹出密码输入框（密码不保存）。
  - 支持搜索。没有条目时显示空状态，说明「连接成功的电脑会自动出现在这里」。
- **远程会话**：
  - 列出本机发起的会话：对方地址、模式（控制 / 仅查看 / 传文件）、持续时间、延迟、帧率、码率。操作：切到窗口、文件传输、切换仅查看/控制、断开。
  - 列出「正在控制本机」的会话：对方地址、时长、权限，可以断开。
  - 没有会话时显示空状态，并给出跳转到「连接」页的按钮。
- **文件传输**：
  - 已连接的会话卡片，带「打开文件传输」按钮。
  - 「仅传文件」快速连接（地址 + 密码）。
  - 本次运行的传输记录：时间、文件名、方向、大小、平均速度、结果；可以清空。
- **设置**（左侧分组：安全 / 画质 / 网络 / 通用，各页是表单，改动立即生效并保存）：
  - **安全**：
    - 临时密码更换频率：每次连接后、每 12 小时、每 24 小时、不自动更换。这项要真正生效；连接页的同名下拉框和这里是同一个设置。
    - 固定密码：8–16 位，可以清除。设置后，临时密码和固定密码都能用于连接。
    - 连接前需要确认：开关；关闭等同于自动接受。
    - 允许被远程控制：默认值。
  - **画质**：默认帧率 30 / 60 / 90 / 144，默认码率自动 / 30 / 14 / 8 / 3 Mbps。新会话使用这两个默认值，会话里的控制中心仍可临时修改。
  - **网络**：监听端口，默认 21118，范围 1024–65535，修改后被控端重启监听；本机地址列表只读。
  - **通用**：主题跟随系统 / 浅色 / 深色，立即切换；显示版本号和配置文件位置，并提供「在访达/资源管理器中显示」按钮。
- 命令行参数仍然优先于配置文件；测量脚本里的 `-password` / `-listen` 等不受影响。
- 不编造示例数据。提交身份按仓库配置（tango），保留 Co-Authored-By 署名。

## Review Focus

1. 配置文件损坏或不可写时，程序照常启动，界面提示原因，不崩溃。
2. 固定密码与临时密码并存时，两者都能通过挑战应答；修改固定密码后，旧的固定密码立即失效。
3. 修改端口时如果有会话正在进行，不中断当前会话，新端口只用于后续连接。
4. 探测在线状态不阻塞界面，窗口关闭时停止探测。
5. Windows 和 macOS 的配置路径都正确，交叉编译通过。
