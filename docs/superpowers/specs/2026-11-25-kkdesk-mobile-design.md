# kkdesk 手机端设计

日期：2026-11-25 · 状态：用户已选定方案，交付实现
界面原型：[docs/design/mobile-prototype.html](../../design/mobile-prototype.html)（浏览器打开，含完整流程、模块图和全部选项）

## 目的

手机扫描电脑上的二维码完成配对，之后在手机上远程查看和操作这台电脑，包括人在外面连家里或公司的电脑。手机只做控制端，电脑仍是现有的被控端。

## 分期（编排方的决定，用户已同意开工）

12 项不在一个版本里做完，按依赖排先后：

- **第 0 步 验证**：Flutter 应用在 iPhone 和 Android 上，用现有局域网「地址 + 密码」连接现有电脑端，显示画面、能点鼠标。测延迟（复用电脑端时钟同步的口径）、帧率、发热/耗电。证明 libwebrtc（flutter_webrtc）和 pion 的 H.264 互通。
- **第 1 期 能用**：扫码配对与跨网、看画面与两种触控、软键盘与快捷键、多屏与画质、剪贴板、局域网直连、App 锁。
- **第 2 期 好用**：文件传输、隐私屏与锁屏、平板适配。
- **第 3 期 补齐**：远程声音、远程开机。

每期独立可用，各自出计划、各自验收。

## 技术方案（编排方的决定）

### 手机端结构

Flutter 工程放在仓库 `mobile/`。
- **媒体与数据通道**：`flutter_webrtc`（libwebrtc，H.264 硬解，`RTCVideoView` 显示）。电脑端编码为 H.264 Constrained Baseline（`internal/codec/vt_darwin.c`），libwebrtc 能直接解。不在手机上跑 Go 的 pion，因为那样要自己做解码和纹理上屏，正是最大风险所在。
- **协议在 Dart 里重写**：局域网信令（`internal/session/signal.go`，TCP JSON 行 + HMAC 挑战）、跨网信令（`internal/rendezvous/client.go`，WSS）、输入事件二进制格式（`internal/input/proto.go`）、画质/多屏/时钟/剪贴板/文件数据通道（`internal/session/*.go`、`internal/files`）。
- **兼容性靠金样本**：Go 侧加测试生成各协议的编码样本（JSON / 二进制）到 `mobile/test/fixtures/`，Dart 测试逐字节比对。以后任一端改协议，两边测试都会失败。
- 本地存储：配对凭据和私钥放 `flutter_secure_storage`（iOS 钥匙串 / Android Keystore）；生物识别 `local_auth`；扫码 `mobile_scanner`。具体包和版本由实现方选择，记进计划。

### 配对协议（新增）

- **电脑身份**：电脑端生成固定设备 ID 和 Ed25519 密钥对，存进本机配置。替代现在每次启动都变的 `KD-` 码（`internal/rendezvous/client.go` 的 `NewCode`）。跨网设备码改为由固定 ID 派生。
- **二维码内容**：`kkdesk://pair?v=1&id=<设备ID>&c=<一次性配对码>&fp=<电脑公钥指纹>&s=<服务器地址>&t=<服务令牌>&lan=<局域网地址列表>`。没有配置服务器时省略 `s`、`t`。配对码 3 分钟过期、只能用一次，过期后二维码自动刷新。
  - `t`（`KKDESK_SERVER_TOKEN`）是共享服务令牌。二维码只在本机屏幕上显示，可以接受；文档里要写明。
- **配对过程**：手机生成自己的 Ed25519 密钥对，经服务器（或局域网直连）向电脑发配对请求，内容包括手机公钥、名称、型号和配对码。双方用 `hash(配对码 ‖ 电脑公钥 ‖ 手机公钥)` 算出 4 位核对码并各自显示。电脑弹窗确认，弹窗里有「以后连接无需确认」复选框，默认不勾。确认后电脑保存手机公钥、名称、免确认标志，手机保存电脑 ID、公钥、服务器信息。
- **连接认证**：手机用私钥签电脑给的随机数；电脑查已配对列表，免确认的直接接受，否则走现有的接受/拒绝弹窗（显示手机名）。手机校验电脑公钥指纹，防止服务器或局域网中间人冒充。现有「地址 + 密码」和设备码连接保持不变。
- **解除配对**：电脑端删除后立即失效；手机下次连接收到明确的「已解除配对」并提示用户。
- **局域网直连**：二维码带局域网地址时，手机先尝试直连电脑的监听端口，用上面的签名认证代替密码；失败再走服务器。

### 电脑端改动（Go / Tango，最小化）

- 连接页卡片加「手机扫码连接」按钮 + 二维码弹窗（倒计时、过期自动刷新）。Go 二维码库自选，许可证须兼容 AGPL-3.0。
- 配对确认弹窗：样式同现有「请求控制本机」弹窗，含核对码、免确认复选框、倒计时。
- 设置 → 安全 → 已配对手机：列表、改名、免确认开关、解除配对。
- 被控提示面板显示手机名。
- kkdesk-server：配对请求转发接口、固定 ID 在线状态。尽量做成新增文件，`server.go` 只做必要的接线（见下面的并行改动）。

### 手机端界面

照原型画：首页（第 05 项 A）、扫码页、核对页（第 01 项流程 ②③⑤）、远程页（横屏全屏、悬浮球、两种触控、键盘快捷键栏）、「我的」页（服务器、已配对电脑、App 锁、主题）。iOS 和 Android 用同一套界面，遵循各自的返回手势和安全区。中文界面。
