# 连接认证 v2

升级后，局域网手输密码和跨网设备码连接需要控制端和被控端都升级。手机走局域网时也需要新版应用。跨网设备码连接必须填写临时密码或固定密码，原先由被控端单独确认的无密码方式已移除。

- 电脑对每次连接签名，密码证明通过 WebRTC 加密通道传输。跨网连接会核对签名与设备码。
- 局域网首次连接显示对方设备码并记住身份。同一地址的身份改变时会拒绝连接。
- 连续输错 5 次密码后暂停密码连接 30 秒，继续输错时最长暂停 15 分钟。
- 手机如果没收到配对的最后确认，可重新扫码或使用新的手动配对码补存记录。

## 隐私屏与锁屏

- macOS 和 Windows 被控端可以在远程会话中用隐私屏遮住本地显示器。默认每次请求都由被控端确认。
- 桌面控制中心增加「本次断开后锁屏」和「锁屏并断开」。被控端可在「设置 › 安全」开启自动锁屏。开启后意外断线会先等待 60 秒，给重连留出时间。
- Windows 隐私屏需要 Windows 10 2004 或更新版本。系统锁屏后需要现场解锁。 [隐私屏与锁屏使用说明](../guide/control#隐私屏与锁屏)
