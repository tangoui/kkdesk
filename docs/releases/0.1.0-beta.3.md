# kkdesk 0.1.0-beta.3（预览版）

预览版，用来在真机上完整验证，再发布 0.1.0 正式版。预览版不会出现在自动更新里，新的预览版需要手动下载。

## 下载哪个文件

| 系统 | 下载 |
| --- | --- |
| macOS（Apple 芯片） | `kkdesk-0.1.0-beta.3-darwin-arm64.dmg` |
| macOS（Intel） | `kkdesk-0.1.0-beta.3-darwin-amd64.dmg` |
| Windows（x64） | `kkdesk-0.1.0-beta.3-windows-amd64-setup.exe` |
| Linux | `.AppImage` 或 `.deb`（x64 / arm64） |
| Android | `kkdesk-0.1.0-beta.3-android.apk` |

其余的 `.tar.gz`、裸 `.exe`、`.patch` 和 `latest.json` 是程序自动更新用的，不需要手动下载。

## 本版新增

- **安装包**：macOS 提供 DMG（打开后把 kkdesk 拖进「应用程序」）；Windows 提供安装程序，按用户安装、不需要管理员，会建开始菜单与桌面快捷方式，可在「已安装的应用」中卸载（检测到锁屏远控组件时询问是否一并卸载）；Linux 提供 AppImage 和 deb。
- Windows 装了锁屏远控组件后，自动更新改写用户目录那份，不需要提权；更新后在「设置 › 安全」一键更新组件。


## 主要功能

- 远程控制、仅查看、文件传输、剪贴板同步，局域网直连或自托管跨网服务（设备码）。
- 连接认证 v2：被控端签名每次应答，密码只在加密通道里验证，连续输错会暂停密码连接。**必须两端都是这个版本**，与更早的构建不兼容。
- 隐私屏、断开后自动锁屏、锁屏并断开。
- Windows 锁屏远控组件：安装后可以远程看到并操作锁屏界面，控制中心「解锁电脑…」可用保存在控制端的密码一键解锁。
- 远程光标形状同步；手机端（iOS、Android）支持隐私屏、锁屏和解锁。

## 已知限制

- **macOS 版没有用开发者证书签名**：第一次打开需要在「系统设置 › 隐私与安全性」点「仍要打开」；每次更新后要重新授权屏幕录制和辅助功能；**不支持 macOS 锁屏远控**（需要正式签名）。
- Windows 隐私屏需要 Windows 10 2004 或更新版本；开始菜单、Alt+Tab、通知和 UAC 界面盖不住。
- Linux 版目前只能传文件。

## 请帮忙验证

局域网和跨网连接、文件传输、剪贴板、隐私屏、锁屏与解锁（Windows）、手机控制。遇到问题请附上 kkdesk.log：macOS `~/Library/Application Support/kkdesk/`，Windows `%APPDATA%\kkdesk\`。
